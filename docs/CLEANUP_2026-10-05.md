## Rollback and future reuse

The snapshot [cleanup-2026-10-05.zip](../tools/future/cleanup-2026-10-05.zip) contains the exact pre-cleanup files, including both removed Sass libraries and the source and bundled JavaScript. It captures the motion implementation already present when this cleanup began, rather than reverting that work to Git HEAD. The archive is under `tools/`, which Jekyll excludes from the published site.

SHA-256: `8B8BCEE489DD34A2B8AF4A44F70AD8B51939B8440806C6708214914E099286D8`.

To inspect or reuse a retired feature without changing the current site, run from the repository root:

```powershell
Expand-Archive -LiteralPath tools/future/cleanup-2026-10-05.zip -DestinationPath tmp/cleanup-restore -Force
```

Copy only the needed block or file from that inspection directory. Restore the relevant import and configuration too if reintroducing a Sass library. The snapshot also contains the inactive SEO options for future Twitter, Facebook, pagination, or search-verification setup.

For a complete rollback, review any newer edits to these files first: this command overwrites every snapshotted file with its pre-cleanup contents.

```powershell
Expand-Archive -LiteralPath tools/future/cleanup-2026-10-05.zip -DestinationPath . -Force
```

Then follow the build and browser checks in [MAINTENANCE.md](MAINTENANCE.md). No Git reset is needed; unrelated files are outside the snapshot.
